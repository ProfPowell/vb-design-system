Theme

Elements

19 design-system documentation components. Each page has a live, themeable example and its full API.

Specimens & samplers

Show the system as it is: type, spacing, tokens, motion, layout primitives, breakpoints, and native UI in the active theme.

<type-specimen>

Typography specimen web component with character grid, weight scale, type scale, and editable sample text.

<spacing-specimen>

Spacing scale specimen web component that reads VB design tokens and renders a visual bar chart with computed values.

<token-specimen>

Unified design token scale display. Renders shadows, radii, borders, colors, or sizes based on the type attribute.

<motion-specimen>

Design token motion scale display. Shows easing curves with animated preview dots and/or durations as bars.

<layout-specimen>

Visual specimen web component for VB layout primitives. Renders each layout-* element with a labeled mini-example and the canonical HTML snippet.

<breakpoint-specimen>

Responsive breakpoint visualization web component. Renders a ruler of viewport breakpoints with a live width readout and a moving cursor for the active breakpoint.

<accessibility-specimen>

WCAG contrast-ratio table and accessibility checklist web component for design-system docs. Computes AA/AAA pass/fail badges from authored foreground/background color pairs.

<component-sampler>

Themed grid of native UI elements. Shows how buttons, inputs, badges, and other components look with the active VB theme.

Color & palette

Build the color system: generate palettes from a seed, map them to semantic roles with WCAG checks, build gradients, and pair fonts.

<color-palette>

Interactive color swatch display web component with click-to-copy and multiple layout modes.

<palette-generator>

Generate harmonious color palettes from a seed color. Extends color-palette with algorithmic palette generation for design systems.

<semantic-palette>

Preview a palette in use as VB semantic roles — button, link, badge, alert — each with its own WCAG contrast chip. Editing happens upstream in or .

<gradient-builder>

Interactive CSS gradient builder with color stops, angle control, interpolation space selection, and one-click CSS export.

<font-pairer>

Interactive font pairing tool — pick heading, body, code, and display fonts from a curated Google Fonts list, preview them in context, edit sample text live, and export as CSS custom properties.

Icons & brand

Document identity: a searchable icon catalog, a curated icon specimen across the size scale, and the brand mark on light and dark surfaces with clear-space.

<icon-set>

Searchable grid of icons in a set, with click-to-copy names.

<icon-specimen>

Curated icon-language specimen: a fixed set of icons across the sizing scale.

<brand-specimen>

Brand mark specimen web component that shows a brand-mark on light/dark surfaces, a size scale, and a clear-space box.

Theming

Round-trip themes: browse curated public token sets, export the active theme as CSS or DTCG JSON, and apply a tokens.json to a preview scope.

<theme-catalog>

Browse and apply curated public design-system token sets — Material, IBM Carbon, Salesforce Lightning, GOV.UK, Atlassian, Tailwind, Bootstrap, Catppuccin Mocha — to a preview scope.

<theme-export>

Collects VB custom property overrides from a scope and emits them as a theme.css block or JSON. The assembly glue for the Theme Composer.

<theme-import>

Apply a DTCG (Design Tokens Community Group) tokens.json file to a preview scope. Sibling of theme-export — paste, file, or URL input feeds a pure deserializer.
