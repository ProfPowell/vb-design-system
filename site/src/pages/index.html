Install

npm install @profpowell/vb-design-system import '@profpowell/vb-design-system'; import '@profpowell/vb-design-system/css';

The first import registers all ${elementCount} elements; the second loads their light-DOM styles. Load Vanilla Breeze tokens and a theme on the page (or your own compatible tokens) and the components adopt it. vanilla-breeze is an optional peer dependency. Read the pack guide for CDN and per-element imports.
